# ADR-0002: Стиль інтеграції

- Статус: **accepted**
- Дата: 2026-11-15

## Контекст
Клієнти мають взаємодіяти з системою через стабільний контракт.

## Розглянуті альтернативи
- GraphQL
- gRPC
- WebSocket

## Рішення
Обрано **REST/HTTP JSON**. Обґрунтування: простота, сумісність з клієнтами, інструменти тестування.

## Наслідки
- (+) простіше підтримувати
- (−) обмеження масштабування; перегляд при зростанні навантаження
- Зміна рішення — новим ADR зі статусом superseded для цього.
