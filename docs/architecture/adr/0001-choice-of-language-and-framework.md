# ADR-0001: Вибір мови та фреймворку

- Статус: **accepted**
- Дата: 2026-11-15

## Контекст
Потрібен стек для навчального сервісу керування задачами з CI, тестами та підтримкою.

## Розглянуті альтернативи
- Node.js/Express
- Java/Spring
- Go

## Рішення
Обрано **Python / FastAPI**. Обґрунтування: швидка розробка, знайомий стек, достатньо бібліотек для задач проєкту.

## Наслідки
- (+) швидкий старт і зрозуміла підтримка
- (−) залежність від екосистеми та її версій
- Зміна рішення — новим ADR; цей запис отримає статус superseded.
